# examples — 可选示例数据（不随应用打包）

这个目录里的东西**不会**进入 `dist/`，也不被应用自动加载。它只是一份可以手动导入的示例，
方便在空库上看清「创作」页长什么样。

## 这是什么

- `creations-sample.json`：9 篇示例帖子 + 4 个示例创作者档案。字段形状与
  `js/creations.js` 里 `normalizeImportedPost()` 接受的导入 JSON 完全一致（`{ "posts": [...],
  "creators": {...} }`，应用会读 `posts`）。
- `assets/`：**没有随仓库提供**。示例 JSON 里的 `assets/creations/...` 路径是相对路径，
  需要你自己把素材放进 `examples/assets/creations/` 才能显示封面/画廊/附件；没有素材时图片会
  加载失败，但帖子、标题、标签、附件行等文字内容仍然可以浏览。

## 怎么导入

1. 构建并运行应用（`npm run build` 后由静态服务器提供 `dist/`，或 `npm run dev`）。
2. 打开「创作」页，点 **导入创作**。
3. 选择 **本地创作 JSON**，选中 `examples/creations-sample.json`。
4. 帖子会出现在库里；「清空导入」可以把它移除，回到真正的空库。

## 为什么不在代码里

示例素材不该进应用的构建产物：它是占位内容，将来会换成更丰富的默认示例，别人 clone 下来也
不需要这些文件。应用默认空库，空态会引导你导入。

## 素材从哪来

原来的示例素材（封面/画廊/头像/简介/附件/视频，共 49 个文件约 156 KB）已从仓库移除。
如果需要还原一套能完整显示的示例，自己准备同路径的文件即可，或只替换 JSON 里的路径指向你
自己的素材。
